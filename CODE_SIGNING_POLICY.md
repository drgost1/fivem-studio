# Code Signing Policy

FiveM Studio is a community fork of
[QB Studio](https://github.com/qbcore-framework/qb-studio) maintained by
[Tufan Studio](https://www.tufanstudio.net).

**Installers built from this repository are not code-signed.** The SignPath
signing programme described by the upstream project applies only to official
QB Studio releases published by the QBCore Framework; their policy lives at
[qbcore-framework/qb-studio/CODE_SIGNING_POLICY.md](https://github.com/qbcore-framework/qb-studio/blob/main/CODE_SIGNING_POLICY.md).

To verify a FiveM Studio download: fetch installers only from
[this repository's releases page](https://github.com/drgost1/fivem-studio/releases)
and compare the file's SHA-512 checksum against the value published in the
release's `latest.yml`. Windows SmartScreen warns on unsigned installers -
that is expected for this fork.
